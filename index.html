The mechanism

One post. One twist. Locked.

01

Post, embedded

A medical-grade stainless threaded post sits in the sole, fully wrapped in silicone. Nothing metal touches skin.

02

Module, aligned

Each module carries a hex insert sized to the post. Set it against the threads — there's one way it seats.

03

Deployed or flush

Twist to raise a module between the toes, or twist it back down flush with the sole. Same sandal, two states.
